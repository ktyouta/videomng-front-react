# お気に入り動画 空表示の刷新 — 仕様

## 目的
お気に入り動画一覧が空のときの表示が「動画が存在しません。」の1行のみで寂しいため、
状態に応じたリッチな空表示（アイコン＋見出し＋補足文＋必要に応じたCTA）に刷新する。

## 対象
- `src/features/favorite/components/videolist/videoarea/FavoriteVideoArea.tsx`（お気に入り動画一覧）
- 他3画面（フォルダ内動画・お気に入り/ホームのチャンネル動画）は状態の意味が異なるため今回は対象外。

## 要件（チェックリスト）
- [ ] 動画・フォルダの両リストが空のとき、1行テキストではなく縦積みの空表示を出す。
- [ ] 空表示は「未登録」と「絞り込み結果0件」の2パターンを出し分ける。
- [ ] 未登録（サーバー検索条件なし かつ サーバー総件数 total が0）のとき:
  - アイコン（ブックマーク系）＋見出し「まだお気に入り動画がありません」＋補足文を表示する。
  - 「動画を探す」ボタンを表示し、押下でホーム（`/video`）へ遷移する。
- [ ] 絞り込み0件（サーバー検索条件あり、またはキーワード絞り込みで total > 0）のとき:
  - アイコン（検索系）＋見出し「条件に一致する動画がありません」＋補足文を表示する。
  - 「動画を探す」ボタンは表示しない。
- [ ] 出し分け判定はサーバー検索条件（カテゴリ/視聴状況/タグ/お気に入り度/フォルダ）の有無と total で行う。
- [ ] キーワード絞り込みはクライアント側のため、total > 0 を利用して「絞り込み0件」側に倒す。
- [ ] スマホ（メディアクエリ未指定のベース）を第一に、タブレット・PCで段階的に拡大するレスポンシブにする。
- [ ] 色は既存トーン（白／`rgb(158,158,158)`／`ICON_CIRCLE_BG_COLOR`）のみ、CTAは既存 `ButtonComponent` を流用し新色・独自ボタンを追加しない。

## 要件（エラー表示の刷新）
- [ ] お気に入り動画一覧の取得エラー時、1行テキストではなくアイコン＋見出し＋補足＋アクションの表示にする。
- [ ] 警告アイコン（`FaExclamationTriangle`）を既存トークン `DANGER_COLOR` で表示する。
- [ ] 「再読み込み」ボタンを表示し、押下で react-query の `refetch` を呼びデータを再取得する。
- [ ] 空表示とエラー表示は共通の器 `FavoriteVideoStatus` を使い、レイアウト（余白・フォント階層・レスポンシブ）を共有する。
- [ ] 空表示の見た目・挙動は本改修の前後で変えない（`FavoriteVideoStatus` へ委譲するのみ）。
- [ ] エラー表示のボタンは空表示CTAと同じ `ButtonComponent`（青系）を流用し新色・独自ボタンを追加しない。

## 要件（他画面への水平展開）
- [ ] favorite の共通器 `FavoriteVideoStatus` / `FavoriteVideoError` は favorite ルート（`features/favorite/components/`）に配置し、favorite 内の各サブ画面から利用する。
- [ ] home は favorite の部品を import せず、home 内に自前の `HomeVideoStatus` を持つ（feature 分離を守る）。
- [ ] フォルダ内動画一覧（favorite）: 空表示は `FavoriteVideoStatus`（フォルダアイコン＋「このフォルダに動画がありません」、CTAなし）、エラーは `FavoriteVideoError`（再読み込み）に刷新する。
- [ ] お気に入りチャンネル動画一覧（favorite）: 空表示を `FavoriteVideoStatus`（動画なしアイコン＋中立文言、CTAなし）に刷新する（エラー分岐は無いため対象外）。
- [ ] ホームのチャンネル動画一覧（home）: 空表示を `HomeVideoStatus`（同上）に刷新する。
- [ ] チャンネル系画面は空表示の発生がまれなエッジのため CTA は付けない。
- [ ] チャンネル系の空文言は特定チャンネルを断定しない中立表現にする（「動画がありません／表示できる動画が見つかりませんでした。」）。チャンネルが空である事実を断定する文言（「このチャンネルに動画がありません」等）は使わない。

## 判定ロジック
- サーバー検索条件あり = `selectedFavoriteVideoCategory` / `ViewStatus` / `Tag` / `FavoriteLevel` / `Folder` のいずれかが非空。
- 未登録 = サーバー検索条件なし かつ `total` が 0/未定義。
- 上記以外の空表示 = 絞り込み0件。
