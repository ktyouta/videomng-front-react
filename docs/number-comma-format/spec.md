# 数値の3桁区切りカンマ表示

## 背景
再生回数・高評価数などの数値が生値のまま表示されており、桁数が多いと読みづらい。3桁区切りでカンマ（例: `1,000`）を付与して可読性を上げる。

## 対象
- 動画統計の再生回数・高評価数（ホーム/お気に入り/チャンネル動画の3画面）
- コメントの高評価数（各コメント/返信コメント、計7コンポーネント）

## 要件

- [x] 数値を3桁区切りカンマ表記に変換する共通関数を `src/utils/CommonFunction.ts` に1つ用意すること
- [x] 共通関数は文字列型・数値型の両方の入力を受け付けること（統計値は文字列、コメントの高評価数は数値のため）
- [x] 値が欠損（undefined/null/空文字）の場合は空文字を返し、既存の「何も表示しない」挙動を維持すること
- [x] 数値変換できない値が渡された場合は元の値をそのまま返し、表示を壊さないこと
- [x] フォーマットのロケールは `ja-JP`（既存 `formatDateJP` と統一）とし、名前付き定数に切り出すこと
- [x] 再生回数の `回` の付与・空値ガードなど既存の表示仕様を変更しないこと
- [x] 動画統計の再生回数・高評価数（3画面）がカンマ区切りで表示されること
- [x] コメントの高評価数（7コンポーネント）がカンマ区切りで表示されること

## 非対象（変更しないもの）
- `dislikeCount` / `favoriteCount` / `commentCount`（UIに表示箇所なし）
- チャンネル登録者数（表示箇所なし）
- レイアウト・配色・余白・HTML要素構成
