# 動画詳細画面 アイコンのタップ可能性向上

## 背景
動画詳細画面（favorite / home / favorite-videochannel の3画面）で、以下のアイコンがタップ可能に見えない。
- 戻る矢印（一覧に戻る）
- メモ/タグ/動画詳細設定の編集モード用アイコン（鉛筆・×・チェック）
- コメントの非表示・再表示・お気に入り・削除アイコン、メモ削除アイコン
- スマホ時のサムネイル右上に重なるアイコン（削除・お気に入り登録・ログイン）

原因は、上記アイコンが色付きのアイコン単体（背景・枠なし）で構成されており、唯一の手がかりが
CSSの`cursor:pointer`と、PCのマウスホバー時だけ表示される吹き出しラベルだったため。
どちらもタッチ操作のスマホでは機能しない。

## 現行仕様（変更前）
- [ ] `IconComponent`（`src/components/IconComponent.tsx`）はアイコンをそのまま描画し、背景・枠は持たない
- [ ] 編集モード用アイコン（鉛筆・×・チェック）はホバー時のみ吹き出しラベルを表示する（`onMouseEnter`/`onMouseLeave`）
- [ ] スマホ時のサムネイル右上アイコン（`IconBadgeButton`）は`background: none; border: none;`で完全に透明

## 変更後の仕様
- [ ] `IconComponent`に円形背景を付与するオプション（`hasCircleBackground`）を追加する。背景色は呼び出し側から上書き可能にする
- [ ] 以下のアイコンで`hasCircleBackground`を有効化し、円形背景色は既存の画面内トークン`#3a3d42`を使う
  - 戻る矢印（`BackToListIcon.tsx`）
  - メモ/タグ/動画詳細設定の 編集(鉛筆)・×(閉じる/キャンセル)・チェック(更新) アイコン（計9箇所）
  - コメントの非表示・再表示・お気に入り・削除アイコン、メモ削除アイコン（計5箇所）
- [ ] スマホ時のサムネイル右上アイコン（`IconBadgeButton`、3画面分）に半透明の円形背景（サムネイル画像の上でも視認できる色）を付与する
- [ ] 円形背景を付けた場合、クリック・ホバーイベントは円の背景側（アイコンの周囲の余白部分）にも反応する（タップ領域が広がる）
- [ ] `hasCircleBackground`を指定しない既存の呼び出し箇所（動画詳細画面以外で使われている`IconComponent`）の見た目・挙動は変更しない
