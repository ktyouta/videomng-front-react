# 動画詳細画面 スマホ文字サイズ適正化

## 背景
ホーム/お気に入り一覧画面のレイアウト刷新に続き、動画詳細画面(ホーム/お気に入り/チャンネル動画の3画面)を対象に、スマホ表示で固定サイズのまま縮小されていなかった文字を適正化する。

## 対象画面
- ホーム動画詳細(`src/features/home/components/videodetail/`)
- お気に入り動画詳細(`src/features/favorite/components/videodetail/`)
- チャンネル動画詳細(`src/features/favorite/components/videochannel/videodetail/`)

## 要件

- [x] コメント欄・メモ欄・検索キーワード欄の見出しは、スマホ幅で16px、タブレット/PC幅で19pxになること
- [x] コメントの日付・いいね数・メモのメタ情報・設定編集のガイド文は、スマホ幅で11px、タブレット/PC幅で13pxになること
- [x] 動画詳細の操作ボタン(再生・お気に入り登録・削除等)の文字は、スマホ幅で12px、タブレット/PC幅で14pxになること
- [x] タグガイド(お気に入りのみ)の見出し・本文は、スマホ幅で14px、タブレット/PC幅で16pxになること
- [x] 動画タイトル・メニュー本文・メニューラベル・ツールチップは変更しないこと(既存のまま)
- [x] ホーム/お気に入り/チャンネル動画詳細の3画面で、文字サイズの定数はそれぞれ独立したファイルに定義すること(値は同一)

## 非対象(変更しないもの)
- 動画タイトル(`VideoTitle`)
- メニュー本文(`MenuParentDiv`)・メニューラベル(`ComboTitleSpan`)
- アイコンホバー時のツールチップ文字(10px)
- レイアウト・配色・余白
