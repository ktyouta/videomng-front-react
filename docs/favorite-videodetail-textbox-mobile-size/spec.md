# お気に入り動画詳細画面 入力欄のモバイルサイズ調整

## 背景
お気に入り動画詳細画面の「キーワード検索」「メモ」の入力欄（共通コンポーネント`TextboxWithButton`使用）は、外枠の高さ（`outerHeight`）がPC/スマホ共通の固定値（37px）になっており、スマホ表示で入力欄・送信ボタンが大きく見えるという指摘があった。

## 原因
`TextboxWithButton.tsx`はwidth系のプロパティ（`outerWidth`/`outerMobileWidth`、`iconWidth`/`iconMobileWidth`）はPC/スマホの出し分けができるが、高さ（`outerHeight`）だけは出し分けの仕組みがなく、呼び出し元も固定値を渡していた。

## 要件
- スマホ表示で「キーワード検索」入力欄の高さが33pxになる
- スマホ表示で「メモ」入力欄の高さが33pxになる
- PC表示（37px）は変更しない
- 「メモ」の送信ボタンのアイコン幅（`iconMobileWidth`）はスマホ表示のみ34pxから24pxに縮小する（「キーワード検索」側の34pxは変更しない）
- 共通コンポーネント（`TextboxWithButton.tsx`・`ClearableTextbox.tsx`）は変更しない（影響範囲を呼び出し元2箇所に限定するため）
- 他画面（ホーム動画詳細、お気に入りチャンネル動画詳細、ホーム画面検索欄）は変更しない

## 対象外とした理由
共通コンポーネント側の変更は影響範囲が読みづらいとの判断（design-proposalで確認済み）により、呼び出し元2箇所のみでの対応とした。中の入力欄自体（`BaseTextbox`）は`ClearableTextbox`が高さを中継していないため常に33px固定であり、これが縮小の下限となる。
