# お気に入り動画詳細画面 パネルのスクロール対応

## 背景
お気に入り動画詳細画面（`FavoriteVideoDetailMenu.tsx`）は、スマホ表示時に一部メニューで `FavoriteVideoDetailPanel` の高さを `655px` に固定している。固定時にパネル自身にスクロール機構がないメニューでは、中身が高さを超えるとパネルの外にはみ出て表示されていた。

## 要件

- スマホ表示で「動画詳細設定」メニューの内容が655pxを超えた場合、パネル内でスクロール表示される
- スマホ表示で「タグ」メニュー（閲覧・編集とも）の内容が655pxを超えた場合、パネル内でスクロール表示される
- PC表示（`height: auto`）は現状通り変更しない
- 「メモ」「公開コメント」「キーワード検索コメント」の3メニューは対象外とする（既存の内部スクロール実装をそのまま維持し、変更しない）

## 対象外とした理由
「メモ」「公開コメント」「キーワード検索コメント」の3メニューは、中の一覧部分（`FavoriteMemoList` 等）に既に `flex:1` + `overflow:auto` の内部スクロールが実装済みで、パネル側に追加すると外側・内側で二重にスクロール領域ができる可能性があるため対象外とした。
